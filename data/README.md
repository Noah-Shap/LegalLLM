# Data Directory

This directory is gitignored. Data files are generated by running the pipeline locally.

## Structure

```
data/
  raw/
    pdfs/           # Downloaded PDF court filings (one per search result ID)
  processed/
    facts_dataset.parquet       # Extracted facts spans + metadata + quality flags
    facts_failures.jsonl        # Per-document failure reasons + diagnostics
    pdf_parse_warnings.log      # pypdf/fitz parsing warnings
```

## Generating Data

```bash
export CL_TOKEN=your_courtlistener_api_token
legallm --query "merits brief" --max_docs 100
```

With OCR enabled:
```bash
legallm --query "merits brief" --max_docs 100 --enable_ocr --tessdata /path/to/tessdata
```

## Output Formats

- **facts_dataset.parquet**: Columnar format with fields `search_result_id`, `facts_text`, `facts_start`, `facts_end`, `pdf_url`, `cite_hits`, `arg_marker_hits`, and more.
- **facts_failures.jsonl**: One JSON object per line with `reason` (e.g., `out_of_scope`, `no_facts_span`, `needs_ocr`) and diagnostic metadata.
